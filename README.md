# Неправильные глаголы

Телефонный квиз без бекенда: видишь русский перевод, тапаешь три формы глагола.

Правила, алгоритм 70/30 и формат прогресса — в [SPEC.md](SPEC.md).

## Как открыть на телефоне

После выкладки на GitHub Pages открой ссылку сайта в Safari или Chrome.

На iPhone: «Поделиться» → **На экран «Домой»**.  
На Android: меню браузера → **Установить приложение** / **На главный экран**.

После первого открытия квиз работает офлайн. Прогресс сохраняется в этом браузере.

## Локально на компьютере

Не открывай `index.html` как файл: словарь не загрузится. Из папки проекта:

```bash
python3 -m http.server 4173
```

Потом http://127.0.0.1:4173/

## Данные

- `verbs.json` — 277 глаголов с переводами
- `build_verbs.py` — пересобрать JSON из Word-файла
