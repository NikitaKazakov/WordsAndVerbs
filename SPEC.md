# Неправильные глаголы — спецификация

Источник истины для одностраничного квиза без бекенда. Если код и этот файл расходятся, править код.

## Цель

На телефоне учить неправильные английские глаголы: видишь **русский перевод**, тапаешь **три формы** в сетке. Запоминаются и смысл, и `v1 / v2 / v3`.

Словарь: все 277 глаголов из `Список неправильных глаголов.docx`, переводы добавлены в `verbs.json`.

## Как открывать

Публичный GitHub Pages, без серверной логики. После первого захода PWA открывается офлайн.

Прогресс хранится в `localStorage` этого сайта и этого браузера. Свернуть, закрыть, открыть завтра — прогресс на месте. Другой браузер или очистка данных сайта — прогресса нет.

## Экран

Один экран, сразу игра, без меню.

- Сверху: текущая серия, рекорд, счётчик «сегодня», переключатель режима.
- Центр: русское значение (1–2 коротких смысла) и подсказка, какую форму выбрать сейчас.
- Сетка 3×4 = 12 крупных плиток.
- Снизу: кнопка «Не знаю», полоска «новые / учу / знаю», мелкая «Сбросить прогресс».

## Раунд

1. Показан русский перевод.
2. В сетке 3 правильные формы этого глагола и 9 ловушек из других глаголов. Ловушки ближе по написанию, если такие есть.
3. Порядок важен: первый тап — 1-я форма, второй — 2-я, третий — 3-я. На выбранных плитках видны номера 1 / 2 / 3.
4. Тап по последней выбранной плитке снимает её. Тап по более ранней снимает её и все следующие.
5. Ровно 3 выбранные плитки — автопроверка, отдельной кнопки «ОК» нет.
6. Три формы — всегда три отдельные плитки, даже если слова совпадают (`cut`, `cut`, `cut` или `sit`, `sat`, `sat`).
7. Успех только если тексты в порядке `v1`, затем `v2`, затем `v3`. Правильные слова в неверном порядке — промах.
8. После ответа плитки сразу зелёные или красные. Под переводом появляются формы **по порядку**: `go → went → gone`.
9. «Не знаю» = ошибка + показ правильных плиток с номерами 1 / 2 / 3 и трёх форм. Молча пропускать нельзя.
10. Для прогресса успех только 3/3 в верном порядке. Неверные слоты красные; невыбранные правильные формы — пунктир.
11. Дальше только по кнопке «Продолжить». Автоперехода нет, тап по сетке после ответа ничего не делает.
12. Серия 5 и 10 — короткая вспышка на экране.

Особые написания в данных:

- `be`: вторая форма `was/were`.
- `do`: первая форма `do` (в исходнике было `do/does`).
- Модальные `can / may / shall / will` остаются как в исходнике, включая `can → could → been able`.

## Режимы

Три режима, прогресс у каждого свой. «Сбросить прогресс» чистит только текущий режим.

Приставка — если после `for`, `mis`, `over`, `under`, `out`, `re`, `un`, `be`, `with` и т.п. остаётся **другой глагол из этого же списка**. `begin` и `read` не приставки: `gin` и `ad` в списке нет.

- **Простые:** глаголы без приставок. Сюда же попадают базы от приставочных (`forget` → `get`, `understand` → `stand`, `become` → `come`) — они уже есть в списке как отдельные глаголы.
- **Приставки:** только глаголы с приставкой (`forget`, `mislead`, `overcome`…).
- **Смесь:** все 277.

Старый прогресс до режимов переносится в **Смесь**.

Переключение режима сразу даёт новую карточку из выбранного набора. Ловушки в сетке тоже только из этого режима.

## Выбор следующего слова: 70 / 30

У каждого глагола: `seen`, `correct`, `wrong`, `streak`, `lastSeen`, `lastWrong`, `lastResult`.

**Знаю:** `streak >= 3`.  
**Учу:** видели хотя бы раз и `streak < 3`.  
**Новое:** `seen === 0`.

```
нужен следующий глагол
        │
        ├─ 70% → пул ошибок (новые, серия < 3, свежие промахи)
        │         вес выше у свежих ошибок и высокого процента промахов
        │
        └─ 30% → пул давних (уже виденные; чем дольше не показывали, тем вероятнее)
                  «уже знаю» приходят только отсюда, с интервалом
```

Интервал для канала «давно не видел» после серии верных:

- серия 3 → 8 часов
- серия 4 → 1 сутки
- серия 5 → 3 суток
- серия 6+ → 7 суток

Правила:

- Одно и то же слово подряд не показываем.
- Пустой пул → берём из другого.
- Пока нет истории (все новые), берём из пула ошибок.
- Знакомые слова сами по себе не выпадают — только через 30%.

После верного ответа: `seen++`, `correct++`, `streak++`, `lastSeen = now`, `lastResult = correct`.  
После ошибки или «Не знаю»: `seen++`, `wrong++`, `streak = 0`, `lastSeen = now`, `lastWrong = now`, `lastResult = wrong`.

## Данные

`verbs.json` — массив объектов:

```json
{
  "id": "begin",
  "ru": "начинать",
  "v1": "begin",
  "v2": "began",
  "v3": "begun"
}
```

Прогресс в `localStorage`, ключ `irregular-verbs-quiz-v1`, формат `v: 2`:

```json
{
  "v": 2,
  "mode": "simple",
  "modes": {
    "simple": {
      "verbs": {
        "begin": {
          "seen": 4,
          "correct": 3,
          "wrong": 1,
          "streak": 2,
          "lastSeen": 1720000000000,
          "lastWrong": 1719990000000,
          "lastResult": "correct"
        }
      },
      "lastId": "begin",
      "currentStreak": 5,
      "bestStreak": 12,
      "todayDate": "2026-09-20",
      "todayCount": 14
    }
  }
}
```

«Сегодня» сбрасывается при смене локальной даты. Серия живёт между сессиями, пока не будет ошибки.
