# Слова и глаголы — спецификация

Источник истины для одностраничного квиза без бекенда. Если код и этот файл расходятся, править код.

## Цель

На телефоне учить английский в четырёх разделах: **слова**, **неправильные глаголы**, **фразовые глаголы**, **обороты**. Всегда видишь русский смысл и выбираешь английский вариант в сетке.

## Как открывать

Публичный GitHub Pages, без серверной логики. После первого захода PWA открывается офлайн.

Прогресс и добавленные тобой карточки хранятся в `localStorage` этого сайта и браузера.

## Экран

- Сверху: серия, рекорд, сегодня.
- Разделы: **Слова / Глаголы / Фразовые / Обороты**.
- У глаголов дополнительно: **Простые / Приставки / Смесь**.
- Центр: русское значение и подсказка.
- Сетка 3×4 для слов и глаголов; у оборотов 2×3, потому что английский длиннее.
- «Не знаю», затем «Продолжить».
- Полоска «новые / учу / знаю».
- «Добавить» — в словах, фразовых и оборотах. «Сбросить прогресс» чистит текущий режим.

## Раунд

Общее: русский перевод на экране, ловушки из того же режима, после ответа только кнопка «Продолжить».

### Слова, фразовые и обороты

1. Один правильный ответ.
2. Тап по плитке — сразу проверка.
3. Успех, если выбран нужный английский текст.
4. «Не знаю» подсвечивает правильную плитку.

### Неправильные глаголы

1. Первый тап — 1-я форма, второй — 2-я, третий — 3-я.
2. На выбранных плитках номера 1 / 2 / 3.
3. Успех только в порядке `v1 → v2 → v3`.
4. Три отдельные плитки даже при одинаковых словах (`cut / cut / cut`).

## Режимы глаголов

Приставка — если после `for`, `mis`, `over`, `under`, `out`, `re`, `un`, `be`, `with` и т.п. остаётся **другой глагол из списка**.

- **Простые:** без приставок, плюс базы от приставочных (`get` из `forget`).
- **Приставки:** только с приставкой.
- **Смесь:** все неправильные глаголы.

## Добавление с сайта

В разделах «Слова», «Фразовые» и «Обороты» кнопка **Добавить**: русское + английское. Карточка сразу попадает в квиз.

Добавленное живёт в `localStorage` вместе с прогрессом. Базовый набор в JSON не меняется. Если такое английское уже есть в базе — не дублируем; если ты добавлял его сам — обновляем перевод.

## Выбор следующей карточки: 70 / 30

У каждой карточки: `seen`, `correct`, `wrong`, `streak`, `lastSeen`, `lastWrong`, `lastResult`.

**Знаю:** `streak >= 3`. **Учу:** видели и `streak < 3`. **Новое:** `seen === 0`.

- 70% — ошибки, новая, серия < 3.
- 30% — давно не видел, в том числе уже выученное.
- Интервалы после серии верных: 3 → 8 ч, 4 → 1 сутки, 5 → 3 суток, 6+ → 7 суток.
- Одно и то же подряд не показываем.
- Прогресс у каждого раздела/подрежима свой.

## Данные

- `words.json` — `{ id, ru, en }` — слова и устойчивые словосочетания вроде `walk the dog`
- `phrasal.json` — `{ id, ru, en }`
- `phrases.json` — `{ id, ru, en }` — идиомы, обороты и интересные предложения
- `verbs.json` — `{ id, ru, v1, v2, v3 }`

Прогресс, ключ `irregular-verbs-quiz-v1`, формат `v: 4`:

```json
{
  "v": 4,
  "section": "words",
  "verbMode": "simple",
  "custom": {
    "words": [{ "id": "cozy", "ru": "уютный", "en": "cozy" }],
    "phrasal": [],
    "phrases": []
  },
  "modes": {
    "words": { "verbs": {}, "lastId": null, "currentStreak": 0, "bestStreak": 0, "todayDate": "2026-09-28", "todayCount": 0 }
  }
}
```

Старый прогресс глаголов (`v: 1` и `v: 2`) переносится в раздел «Глаголы». С `v: 3` идиомы вроде `it's not my cup of tea` переезжают из слов в обороты вместе со статистикой.

## Вне скоупа

Обратный квиз, звук, аккаунты, синхронизация между телефонами, жизни, таймер, добавление неправильных глаголов с сайта.
